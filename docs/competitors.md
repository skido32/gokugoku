# 競合調査

> 初回調査: 2026-11-16 / 更新: 2026-11-23
> 情報源は、アプリ紹介のブログ(多くはアフィリエイト記事)、ストアの説明・レビュー、作者が実際に触った結果。
> **公式の仕様は取得できていない。**「確認済み」と書いたもの以外は、実際に触って確かめること。

## 1. 位置づけ
- **ゴクゴクは、双子に特化した、シンプルな授乳記録アプリ。** ストアの表示は「ゴクゴク - 双子の授乳記録」。
- **最も近い競合は、ミルクのーと。** その手軽さ(登録なし、授乳に特化)に、**夫婦の共有**と、**1画面で2人分の記録**を足す。
- ほかに意識する競合は、**ぴよログ**と**授乳ノート**だけ。
- 市場全体で勝つことは目指さない。**双子の夫婦という小さな市場で、選ばれる理由をはっきりさせる。**

## 2. 比較の対象(3つ)

| アプリ | 特徴 | 弱点・不満 |
|---|---|---|
| **ミルクのーと**(最も近い) | ミルクの時間に特化。**ウィジェットから1タップ**で記録。次の授乳時刻の通知。ホームで最後の授乳時刻を表示。登録・ログインなし | **夫婦の共有、複数人の記録に非対応**(実際に触って確認済み、2026-11-22) |
| **ぴよログ**(定番) | ワンタップ入力。夫婦でリアルタイム共有(招待コード方式)。授乳タイマー、グラフ、音声入力など。App Store 評価 4.8(11万件超)。複数の赤ちゃん(双子・第二子)の登録に対応 | 項目が多く、**誤タップが起きる**(例:「ミルク」のつもりが「搾乳」)。記録が細かすぎて、見返すのが面倒になる。**双子を1画面で記録できるかは未確認** |
| **授乳ノート** | 授乳・おむつに特化。左右別の授乳タイマー、ウィジェット。起動が速い。複数の子どもの切り替えに対応。家族共有あり | **共有が弱い**(下記 6)。登録時に多くの個人情報を聞かれる、メルマガ登録を求められる、というレビューがある |

## 4. 差別化
**「登録なし・夫婦の共有・1画面で2人・シンプル」の4つを、同時に満たすアプリは見当たらない。** 一言で言えば、「ミルクのーとの手軽さに、夫婦の共有と双子の記録を足したもの」。

| 相手 | 勝てる点 | 根拠の確かさ |
|---|---|---|
| ミルクのーと | 夫婦の共有、双子の同時記録 | 確認済み |
| ぴよログ | 授乳だけに絞ったシンプルさ、誤タップの起きにくさ、登録なし | 不満はレビューで確認。双子の記録の手数は未確認 |
| 授乳ノート | 共有の確かさ(冪等な再送、重複の警告、ポーリング)、登録の軽さ | 共有の弱さは古い投稿が中心。こちらの確かさは、実機で未検証 |
| 共通 | 個人情報の少なさ(メールも持たない)、広告なし、90日で削除 | 設計の方針 |

## 5. 不利な点
- **ウィジェットと通知が、MVP にない。** ミルクのーとの中心の強みで、乗り換えると手数が増える。**最大の弱点。**MVP の直後に、ウィジェットを入れる。
- **ぴよログが双子を1画面で記録できる場合**、ぴよログに対する差は「シンプルさ」と「登録なし」だけになる。
- **真似されやすい。** ミルクのーとが共有を足せば、差は縮まる。
- **市場が小さい。** 双子の家庭は、出生全体のおよそ1%程度とされる(要確認)。届けるには、多胎のコミュニティでの紹介が中心になる。
- **記録の移行ができない。** 対象は、新しく使い始める家庭か、今のアプリに不満のある家庭。
- **シンプルなだけでは足りない。** 機能を絞るほど、見た目と手触りの気持ちよさが、選ばれる理由として大きくなる。
- 無料で十分なアプリが多い。収益化は、今は考えない。

## 6. 調査メモ: 授乳ノートの「共有が弱い」の中身(2026-11-16)
- Google Play のレビューへの返信で、開発元が**家族共有機能の不具合を認めている**(2024年8月)。
- 夫婦の端末間でデータが同期されない、Android 側の相手に記録の時刻が正しく表示されない、という報告がある。
- 共有は後から追加された機能で、2019年時点で、共有を使うのは利用者の約20%(主な利用者は母親)。もともと母親1人の記録アプリだったとみられる(推測)。
- **古い投稿が多く、現在も続いているかは未確認。**同期の難しさは、他のアプリでも報告されており、このカテゴリ全体の課題。
