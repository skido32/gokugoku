# ゴクゴク UI デザインの要件

デザインを作るための要件。仕様書(`spec.md` 6章)と設計書から、画面に関わることだけを抜き出した。
決まったデザイン(色の値、文字の大きさ、余白)は、`design.md` 5章に書き戻す。

## 1. 誰が、どんな場面で使うか
- 双子(または1〜4人の子ども)を育てる夫婦。2人とも、自分のスマホで使う。
- **深夜、暗い部屋で、片手で赤ちゃんを抱えながら**、もう片方の親指で押す。寝ぼけている。
- 2人に同時に飲ませることが多い。「どっちに、いつ飲ませたか」を夫婦で取り違えたくない。
- 開いてから記録するまでを、**1タップ**にしたい。

## 2. 方向性
- **シンプルで、迷わない。** 授乳の記録だけに絞る。機能を足すより、押しやすさと読みやすさを優先する。
- **主な使い手は、授乳するママ。** ピンクとベージュを基調に、やさしく、かわいい見た目にする。マスコット(顔のついたミルクのしずく)と、子どもの顔のアイコンを使う。
- **夜に眩しくない。** 夜はココア色の配色(ダークモード)にする。
- ピンクはアクセントとして使い、地はベージュにする(子どもの色の「ピンク」を埋もれさせないため)。
- 決まった色・文字・大きさは、`design.md` 5.4 にある。

## 3. 守る条件
| 条件 | 内容 |
|---|---|
| ボタンの大きさ | 最小 56px。主なボタンは、親指の届く画面の下半分に置く |
| 子どもの区別 | **色と位置(左右固定)**で区別する。色だけに頼らず、名前を常に添える |
| 確認なし | 記録のボタンは、確認ダイアログを出さずに即記録する。完了は、短い表示と振動で伝える |
| 取り消し | 誤タップは、直後の「取り消し」で戻せる |
| 文字の拡大 | OS の文字サイズを大きくしても崩れない |
| 判断しない | 授乳の量や間隔が適切かどうかは、表示しない・助言しない(記録の道具に徹する) |

## 4. 子どもの色
色は名前で持つ(DB の値)。実際の色は、デザインで決める。ライトとダークの両方で、背景と文字の読みやすさを保つ。

| 名前 | 割り当て順 |
|---|---|
| `blue` | 1人目 |
| `pink` | 2人目 |
| `green` | 3人目 |
| `orange` | 4人目 |
| `purple` | 変更用 |
| `yellow` | 変更用 |

## 5. 画面

### 5.1 ホーム(最重要)
子どもごとの「前回からの経過時間」と「記録ボタン」、「全員」ボタン、直近の履歴。

**子どもの人数で配置を変える**
- 1人: 経過時間とボタンを、1つだけ大きく出す。「全員」ボタンはない。
- **2人: 左右に並べる(基本の形)。** 下に「ふたりに授乳」。
- 3〜4人: 縦に並べ、各行の右に「授乳」ボタン。下に「みんなに授乳」。
- 上から、経過時間のカード → 直近の記録 → 授乳ボタン → メニュー(ホーム / 履歴 / 設定)の順。ボタンは親指の届く下に置く。

**表示する内容**
- 子どもの名前と色、前回の授乳からの経過時間(例: 「2時間10分前」、1分ごとに更新)、前回の時刻。
- 記録がまだない子どもは「記録なし」。
- 直近の履歴(24時間分、新しい順): 時刻、子ども(「全員」は「あお・もも」のようにまとめる)、種類(ミルク / 母乳)、量(任意)、記録者(パパ・ママなどの呼び名)。

**状態**
| 状態 | 見せ方 |
|---|---|
| 記録した直後 | 振動し、カードが「たった今」になる。下に「記録しました」を5秒出し、[ミルク][母乳][混合](1タップで種類を変える)、[量を入れる]、[取り消し] を置く。押したボタンは3秒間「記録しました」になり押せない |
| ふたり(全員)を記録した直後 | 「ふたりに記録しました」と子ごとの種類を出す。[直す] で、全員分の種類と量を1画面で直す入力を開く |
| 量・種類の入力 | 種類の3択、量(±10ml とよく使う量)、時刻。混合は「足したミルクの量」。母乳は量の欄を出さない。設定でオンにすると、記録の直後に自動で開く |
| 送信中 / 未送信 | 該当の履歴の行に、小さく示す。失敗が続いたら「再送」 |
| 重複の知らせ | 「ママが2分前に記録済みです」。記録は受け付けた上で知らせ、取り消しを促す |
| パートナーの記録 | 5秒ほどで、画面に反映される(特別な演出は不要) |

### 5.2 初回ガイド
ログイン画面はない。初回起動で、すぐに始まる。
1. 自分の呼び名(例: パパ、ママ。20文字まで)
2. 「家族を作る」/「招待コードで参加」/「引き継ぐ(機種変更)」を選ぶ
3. 家族を作る場合: 家族名 → 子どもの名前(2人分。ニックネーム可。生年月日は任意) → パートナーを招待(招待コードとリンクを共有。後でもよい)
4. 招待コードで参加: 8文字のコードを入力(リンクから開いた場合は入力済み)

### 5.3 履歴
- 日付ごとの一覧(保持は90日)。
- 1件ごとに、種類・量・時刻を修正、削除できる。
- 時刻を指定した、後追いの記録(未来の時刻は不可)。

### 5.4 設定
子ども(名前・色・並び順・**いつもの種類**・追加・削除)、家族のメンバー(外す・退出)、招待、押したら量の入力を開く(端末ごと)、引き継ぎコードの発行、他の端末のログアウト、アカウントの削除。
いつもの種類は「ミルク / 母乳 / 混合」から選ぶ。混合には「母乳のあとに、ミルクを足すとき」と添える。
「1人だけの家族で端末を失うと、データは戻せない」ことを案内する。

### 5.5 招待受諾
招待リンクを開いたときの参加確認(家族名と、招待した人の呼び名を出す)。

## 6. 進め方と、決まったこと
デザイン案は、Claude のデザイン(非公開)で作った。ホーム(昼・夜・1人・4人)、押した後の挙動、初回ガイド、履歴、設定、招待受諾がある。

決まったこと:
- 配色はピンクとベージュ(昼)、ココア(夜)。
- 種類は「ミルク / 母乳 / 混合」。子どもごとに「いつもの種類」を持ち、例外の回は記録した直後に1タップで変える。
- 「記録しました」は5秒、二度押しの防止は3秒。5秒を過ぎた後の修正・削除は、履歴から行う。
- 「全員」ボタンの表示は、2人なら「ふたりに授乳」、3〜4人なら「みんなに授乳」。
- 3〜4人の家庭で全員分を直す入力は、縦にスクロールさせる。
